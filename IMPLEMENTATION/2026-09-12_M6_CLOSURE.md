## Uso e limiti

Il plugin QA è disconnesso e il tunnel fermo al termine del test. Non è un collegamento permanente al Vault reale. Per usarlo occorre avviare esplicitamente il client locale sul Vault autorizzato e riconnettere il plugin. Profilo di prova: .local/m6-tunnel/profile/limen-m6-qa.yaml; client ufficiale v0.0.14 sotto .local/m6-tunnel/. Credenziale solo tramite variabile d’ambiente valorizzata in memoria dal Portachiavi, con organizzazione esplicita. Nessuna porta pubblica: autorizzazione remota tramite tunnel/workspace, server locale stdio.

Percorso UI verificato per revoca: Settings → Plugins → LIMEN Vault M6 QA → Plugin actions → Disconnect. Tunnel amministrabile nella Platform → Tunnels. Le impostazioni sono state verificate il 12 settembre 2026.
