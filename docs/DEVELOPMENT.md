# Development & Build Guide

## Prerequisites
- Node.js (>= 20.0.0)
- `pnpm` (>= 9.0.0)

## Commands

```bash
# Install dependencies
pnpm install

# Run web app dev server
pnpm dev:web

# Run desktop app dev server
pnpm dev:desktop

# Run test suite & prohibited dependency guards
pnpm test

# Run TypeScript type check
pnpm typecheck

# Production build
pnpm build
```
