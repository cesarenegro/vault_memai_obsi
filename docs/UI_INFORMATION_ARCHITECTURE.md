# UI Information Architecture

## Desktop Application Screens

1. **First-Run UX**: Welcome screen with `[ CREATE NEW VAULT ]` and `[ OPEN EXISTING VAULT ]`.
2. **Home**: Header bar, Vault status banner, Ask Knowledge primary CTA, Category quick-links, and metrics.
3. **Ask Knowledge**: Conversational AI interface (UI Shell with honest AI Not Configured state).
4. **Knowledge**: Category sub-browser for Clients, Projects, Brands, Positioning, Packaging, Methods, Case Studies, Research.
5. **Sources**: Material file manager for `20_RAW_SOURCES`.
6. **Search**: Offline local search interface with query and filter controls.
7. **AI Outputs**: Document viewer for drafts in `80_AI_OUTPUTS`.
8. **Proposals**: Human review surface for candidate knowledge proposals in `90_PROPOSALS`.
9. **Snapshots**: Local vault backup versioning and SHA-256 integrity browser.
10. **System**: Local Mac environment diagnostics.
11. **Settings**: Vault root paths and Obsidian launcher preferences.
12. **Open in Obsidian Action**: Header action button with local installation detection.

## Web Application Screens

1. **AI Knowledge Landing**: Dashboard with MEMAI card (`NOT CONFIGURED`) and LIMEN Vault card.
2. **System**: Basic web client environment status.
3. **Desktop App**: Release information and desktop installation guidance.
4. **Documentation**: Product architecture, security model, and usage guidance.
